# Add lesson sources across IT PATH and AUTO PATH

## Goal
Give every lesson a quiet, readable source line using the verified references already assigned to that lesson, without interrupting the teaching flow or changing assessments.

## What will change
- Add a small-print **Lesson sources** line directly beneath the lesson reading and quick-reference material.
- Show only references assigned to the current lesson, with the publisher and source title linked to the original page.
- Keep video recommendations in the existing **Watch and read** area; the small-print citation line will prioritize written references.
- Apply the same presentation to IT PATH and AUTO PATH, including phone layouts.
- If a lesson has no usable written reference, omit the line rather than inventing or mislabeling a source.

## Coverage and quality
- Verify that every active IT PATH and AUTO PATH lesson has at least one written reference.
- Add an automated coverage check so future lessons cannot silently ship without a source.
- Keep source URLs in the existing checked source catalogue, preserving nightly link validation and original wording safeguards.

## Technical details
- Reuse each active course’s topic-specific resource records instead of duplicating citation data inside lesson prose.
- Add one focused citation component to the lesson view, using the existing typography and external-link behavior.
- Validate source-to-lesson matching, mobile wrapping, type safety, tests, and the live lesson page.
