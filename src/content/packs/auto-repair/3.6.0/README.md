# AUTO PATH 3.6.0

An interactive diagnostic training platform designed to teach practical, hands-on automotive repair through simulated real-world service orders.

Key: `auto-repair@3.6.0`

- 9 qualifications
- 102 sections
- 408 concepts
- 202 skills
- 3521 questions
- 9 assessments
- 306 sources

This package is isolated: nothing outside this folder belongs to it.
Activate it with `bun run domain:activate -- auto-repair@3.6.0`, which runs the
checks again and refuses if anything blocking is open. `bun run domain:rollback`
puts the previous subject back.
